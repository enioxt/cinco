# A escada: por onde começar, e quando subir

**Regra que atravessa a escada:** só se sobe um degrau quando o de baixo **produziu resultado no
trabalho real da pessoa**. Degrau pulado vira ferramenta instalada e não usada — que é pior que
ferramenta ausente, porque ela planeja em cima de uma capacidade que não exerce.

| Degrau | Onde ela está | O que destrava AQUI | Sobe quando |
|---|---|---|---|
| **D0 · Navegador** | ChatGPT/Claude/Gemini na aba | conversa melhor: contexto colado, pergunta com critério, recusa de resposta sem fonte | ela sente falta de **memória entre conversas** |
| **D1 · Projeto** | mesma IA, com projeto/instrução fixa | instrução permanente + arquivos de referência; o assistente para de esquecer quem ela é | ela quer que a IA **leia os arquivos dela** |
| **D2 · Máquina** | Claude Code · Codex CLI · Antigravity · Cursor | a IA lê e escreve no computador dela; aqui nasce o `CLAUDE.md`/`AGENTS.md` do trabalho dela | ela repete o mesmo pedido 3× |
| **D3 · Skill** | comando próprio | o pedido repetido vira `/comando` versionado — deixa de depender de lembrar como pedir | ela precisa de **dado que não está no disco** |
| **D4 · Integração** | MCP · API · WhatsApp · planilha · banco | a IA passa a ver a fonte viva; sai do "cole aqui" | o fluxo roda sozinho e alguém depende dele |
| **D5 · Governado** | gates + prova + HITL | o que roda sem ela na frente **prova que rodou**; erro fica visível em vez de silencioso | — |

**Como conduzir, e é o oposto de vender ferramenta:** a pergunta nunca é *"quer instalar o X?"*.
É *"o que você repetiu esta semana que gostaria de não repetir?"*. O degrau sai da dor, não do
catálogo. Ferramenta escolhida antes da dor é a definição de solução procurando problema.

**Sobre qual IDE:** a escolha é **do cliente** (`R-ARCH-001`) — nunca inferida, nunca imposta.
O que muda entre elas é onde a instrução permanente mora, e isso se declara sem opinar:
Claude Code lê `CLAUDE.md` · Antigravity e Cursor leem `AGENTS.md` · Windsurf lê `.windsurfrules`.
**O `AGENTS.md` é o denominador comum** — quem escreve nele primeiro não refaz o trabalho ao
trocar de ferramenta. Isso é fato de compatibilidade, não recomendação de marca.

**O que o EGOS entrega em cada degrau, e o que ele NÃO entrega:** entrega o método, os gates e as
skills que já existem (`KIT_MANIFEST.yaml` é a allowlist — omissão significa privado, por desenho).
Não entrega o kernel inteiro, não entrega dado de cliente, e não promete degrau que a pessoa ainda
não sustenta. **D5 sem D2 não existe:** governança sobre trabalho que não roda na máquina dela é
teatro.
